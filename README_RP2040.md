## 🚀 How to Run in VS Code:

### Method 1: Quick Run (Recommended)
1. Open [`blink.py`](file:///f:/Nemr/COMPINE/compine/blink.py)
2. Press **`Ctrl + Shift + P`**
3. Type: **`MicroPico: Run current file`**
4. Press Enter

### Method 2: Upload to Device
1. Open [`blink.py`](file:///f:/Nemr/COMPINE/compine/blink.py)
2. Press **`Ctrl + Shift + P`**
3. Type: **`MicroPico: Upload current file to Pico`**
4. Press Enter

### Method 3: Use Toolbar Buttons
Look for **MicroPico** buttons in the bottom status bar:
- **▶️ Run** - Run the current file
- **📤 Upload** - Upload to device
- **🔌 Connect** - Connect to COM6

---

## 🔍 Troubleshooting:

### If COM6 doesn't work:
1. Press **`Ctrl + Shift + P`**
2. Type: **`MicroPico: Connect`**
3. Manually select **COM6**

### If you don't see MicroPico commands:
1. Reload VS Code: **`Ctrl + Shift + P`** → `Reload Window`
2. Check that extension **Pico-W-Go** is enabled

## 📝 Expected Result:

When you run `blink.py`:
- The built-in LED on RP2040 will **blink ON/OFF** every 1 second
